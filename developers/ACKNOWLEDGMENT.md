# ACKNOWLEDGMENT.md — what you accept when you publish or play here

This file is the developers' acknowledgment. It is in the REPO on
purpose — not buried in an app screen — because the platform's openness
is not a fine-print thing. It is the whole deal:

1. **EVERYTHING IS EXPOSED.** Packages are plain folders. Indexes are
   plain JSON. Data is plain files. The pck format is Godot's own,
   unencrypted by choice. Saves are portable files inside the GOGAs
   tree. There is no obfuscation, no anti-tamper, no phone-home, no
   kill switch, no DRM, no account, no server of ours. If you publish
   here, you published it OPEN.

2. **EVERYTHING IS WIDE-OPEN.** The engine validates structure (the
   strict validator), not taste, not opinion, not business models. No
   game is "ours-only", no feature is license-gated, no shelf is
   pay-to-ride. The tiers (official/community/hobbyist) are a trust
   DISPLAY, not a permission: a hobbyist game plays exactly like an
   official one.

3. **EVERYTHING IS HIJACKABLE.** Your published game can be forked,
   re-skinned, data-flavored, localized, decompiled, studied and
   remixed by anyone who downloads it — that is the platform's stated
   design (MODDING.md is written aggressive on purpose). Do not publish
   here if that trade is not for you; nothing else changes for you if
   you do.

4. **NOTHING IS ME-ONLY.** The owner's repo is "official" because the
   engine hardcodes it — not because the platform is walled around it.
   Any repo can serve the same files, any source can join the feed, any
   game can use every feature the box ships (coins, LAN, saves,
   achievements, the store shelf). The engine takes no cut of anything.

5. **THE PLAYER OWNS THE BOX.** The GOGAs tree is the player's folder
   (public storage on Android, next to the exe on Windows). Local edits
   are local. Uninstall and reinstall kills local mods and restores the
   source's copy. No local change ever climbs back into a source, a
   repo, or another player's box.

6. **THE LAWS OF THE LAND ARE YOURS TO FOLLOW.** The platform ships no
   legal advice and draws no content lines of its own (there is no
   moderation, no reporting-into-removal, no age enforcement beyond the
   box's simplified play-button door). You carry your own jurisdiction's
   law — copyright, age restrictions, content legality, export rules —
   for what you publish, what you mod, and what you run. The platform's
   tools are neutral; the responsibility is not ours because the
   machine that ran it was.

7. **REPORTS ARE STRUCTURAL, NOT MORAL.** The report flow (REPORTING.md)
   exists for broken ids, broken packages and misrouted reports —
   github issues with the game id, triaged to the right repo. "I do not
   like it" is not a report; "games are not a must" is the platform's
   whole answer.
