# Candy Rush — assets (this game's concrete sources)

> Repo-wide asset **policy**, manifest schema and re-download tooling live in
> the general guide: [docs/ASSETS.md](../../../docs/ASSETS.md). Full per-file
> audit trail: [`../assets.manifest.json`](../assets.manifest.json).

Re-derive everything from the original CC0 sources (downloads included):

```bash
python3 scripts/derive_candyrush_assets.py    # from repo root
python3 projects/candyrush/tools/gen_sfx.py   # synth SFX
```

## The four skins and where their art comes from

| skin | source (all CC0 1.0) | notes |
|---|---|---|
| Candy Shop | OGA ["Candy Match 3"](https://opengameart.org/content/candy-match-3) | glossy sheet sliced on a 100px grid; real striped/wrapped/bomb sprites |
| Gem Vault | OGA ["Gem Match 3 Set"](https://opengameart.org/content/gem-match-3-set) by Andrew Tidey | 5 picks from 4 shapes × 6 colors; specials are code-drawn overlays |
| Retro Fruits | OGA ["Pixel Fruit Pack"](https://opengameart.org/content/pixel-fruit-pack) | apple recolored red→green (deterministic) to free red for the strawberry |
| Neon Arcade | derived in-repo | hue-shifted candy set + dark tinted bg (`scripts/derive_candyrush_assets.py`) |

Backgrounds: the pack's candy-land painting (cover-cropped 720×1280) plus
three tinted variants of its blur companion. FX: 8-frame explosion strip.

## Audio

- Match pops + deep pop: OGA "Pop sounds" + "bubbles 'pop'" (CC0 wavs/ogg)
- Music loop: OGA ["Happy Adventure (Loop)"](https://opengameart.org/content/happy-adventure-loop)
- UI clicks/confirm/error/buy + win jingle: Kenney packs (same CC0 files also
  vendored in the jellyjump project)
- coin / star / sparkle / lose / swap / boom: generated by
  `tools/gen_sfx.py` (numpy, deterministic — repo convention for gaps)
