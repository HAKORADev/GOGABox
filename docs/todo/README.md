# TODO — the waiting room

The owner's order (the 2026-09-19 break round): the box gets a todo system
so both sides stay ready for when work returns. The owner is NOT abandoning
the project — just taking a small rest to think about some stuff.

## The two folders

- **`pending/`** — things waiting for work. The list lives in
  `pending/pending.md` (one numbered section per item).
- **`done/`** — finished things. THE MOVE LAW: when a pending thing is
  done, its section MOVES out of `pending/pending.md` into `done/` as its
  own file (`done/<name>.md`). Nothing is ever deleted — the record stays.

## When work returns

1. Read `pending/pending.md` top to bottom.
2. Start at item 1 (or wherever the owner points).
3. When an item ships, move it to `done/` and leave a one-line result note
   in its place if a new item depends on it.

Nothing here schedules itself — the owner green-lights every round.
