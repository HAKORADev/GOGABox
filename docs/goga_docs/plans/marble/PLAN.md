## Chain engine laws (design notes to self)

- distances in px along an arc-length-resampled Catmull-Rom sample table.
- one array of marbles ordered by dist; groups = runs separated by gaps.
- the front group rolls at level speed; back groups roll at catch-up speed
  until touching the group ahead.
- insert-on-shot = project the shot onto the path, land between neighbors.
- pop run >= 3; gap collapse re-joins; cascade if the join makes a run >= 3.
- BACK pushes everything back by N px; quota stops spawns; mouth eats at the
  end; slow zone last 15%; danger pulse last 12%.

## Testing gates (the owner's anti-40-bugs law)

- probe: deterministic chain sim (insert/pop/join/back/slow/eat) all green.
- flow_test: boot/finish/plays counter.
- films: menu, levels menus, path preview, each shooter mode, powerups, coin,
  challenge, cleared menu, lose flow, 20:9 scaling eye pass.
