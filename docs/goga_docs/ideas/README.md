# ideas — general GOGABox product ideas

Structured (but not yet scheduled) ideas about the box itself: menu UX,
economy, badges, search, notifications, ads, anything that is not a single
game's design. When the owner approves one for a release, it moves into the
matching `plans/PLAN_vX.Y.Z.md` task list.

## The system docs (owner-specced, document-only)

| file | system |
|---|---|
| `LAN_MULTIPLAYER.md` | the LAN multiplayer system — host/join sessions, the PLAYERS badge, the hold screen, the ten-seconds law, real-only seats |
| `TOPUP_SYSTEM.md` | the top-up system — GOGACoins from anywhere in the box converted into a game's own currency (scrap, rockCoins, ...) |
