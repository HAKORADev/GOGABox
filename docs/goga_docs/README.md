# goga_docs — GOGABox planning home

Owner-directed home for everything we think about before/while building.
Nothing here ships to players — it is our memory so ideas are not lost.

| folder | purpose |
|---|---|
| `gogames_ideas/` | GDDs (game design docs) for the games inside the box — one file per game idea |
| `ideas/` | general product ideas (menu, economy, meta, future features) |
| `plans/` | version plans — what each release ships and why (`PLAN_v0.1.0.md`, `PLAN_v0.0.9.md`, ...) |
| `brainstorms/` | raw brainstorm dumps, not yet structured |

Rule of thumb: an idea starts in `brainstorms/`, gets structured into
`ideas/` or `gogames_ideas/`, and becomes a `plans/PLAN_vX.Y.Z.md` when the
owner green-lights it for a release.
