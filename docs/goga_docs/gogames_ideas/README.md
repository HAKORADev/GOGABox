# gogames_ideas — GDDs for games inside the box

The full name dump of future game ideas lives in `FUTURE_GAMES.md` (the
parking lot — names only, nothing scheduled). One markdown file per game
appears here once that game is picked, named after the game's registry id
(e.g. `snake.md`, `hopper.md`). A GDD collects: one-line pitch, core loop,
controls, scoring/GOGACoin economy, unlock/meta hooks, art direction,
and open questions for the owner.

When a game here is approved for a release, it gets a task entry in the
matching `plans/PLAN_vX.Y.Z.md`.
